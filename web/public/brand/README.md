# Stead public assets

Safe to commit to the public repo (for example under `public/` and `docs/`).

- `logo/stead-mark.svg`, `logo/stead-mark-dark.svg`: the Cradle mark (a position held inside guard rails, with two limit marks).
- `logo/stead-wordmark.svg`, `logo/stead-wordmark-dark.svg`: mark + `Stead` in Hubot Sans 800, text already outlined to paths (no font needed).
- `logo/favicon.svg` (48px, square tile with the top-right cut) and `logo/app-icon.svg` (512px, for social cards and the README header).
- `icons/*.svg`: the permitted UI icons (16×16, stroke 1.6, currentColor).
- `stewards/*.svg`: steward code tiles, light and dark.
- `ROADMAP.md`: for the README.
